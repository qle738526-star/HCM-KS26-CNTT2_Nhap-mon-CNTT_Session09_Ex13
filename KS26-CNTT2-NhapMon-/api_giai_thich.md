 API
Khái niệm
API (Giao diện lập trình ứng dụng) là cầu nối trung gian cho phép các phần mềm giao tiếp với nhau.
- Ví dụ: Giống như nhân viên phục vụ chuyển yêu cầu gọi món từ khách hàng xuống nhà bếp.

Vai trò trong SmartCampus
- Kết nối ứng dụng di động với máy chủ nhà trường.
- Lấy dữ liệu lịch học và phòng trống an toàn.
