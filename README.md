

# SmartCampus

Ứng dụng di động **SmartCampus** giúp sinh viên PTIT *tra cứu lịch học*, phòng trống và nhận thông báo từ nhà trường.

- Tính năng:
  - Tra cứu lịch học theo mã sinh viên
    - Xem theo tuần và học kỳ
  - Xem danh sách phòng trống theo tòa nhà

[Trang chủ CLB PTIT](https://clblaptrinh.ptit.edu.vn)

![Logo SmartCampus](https://via.placeholder.com/150/003366/FFFFFF?text=SmartCampus)

> **Cảnh báo:** Dự án đang phát triển thử nghiệm, chưa dùng chính thức.

---

### Cài đặt

```bash
git clone [https://github.com/clb-lap-trinh/smartcampus.git](https://github.com/clb-lap-trinh/smartcampus.git)
npm install
npm start

```

### Ghi chú & Sửa lỗi

Dùng dấu gạch chéo ngược (`\`) để hiển thị ký tự đặc biệt như `*` hoặc `#`.

**Lỗi cú pháp:**

1. Bảng thiếu dòng phân cách (`| :--- | :--- |`).
2. Task List thiếu khoảng trắng (`-[x]` sai thành `- [x]`).

**Đã sửa:**

| Tính năng | Trạng thái |
| --- | --- |
| Tra cứu lịch học | Xong |
| Push notification | Đang làm |

* [x] Tra cứu lịch học
